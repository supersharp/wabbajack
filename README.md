# Wabbajack

> This is a fork of [Wabbajack](https://github.com/wabbajack-tools/wabbajack). 

## Differences compared to the upstream release:
- Allows you to manually specify the game install directory.
- The builds are unsigned.

Wabbajack is an automated Modlist Installer that can reproduce an entire modding setup on another machine without bundling any assets or re-distributing any mods.
